# 酒馆世界观

这个私有项目包含世界观资料与 SillyTavern 酒馆程序。

- `世界观工程/`：Obsidian 世界观库，含草案、正式设定、模板和画布。
- `SillyTavern/`：酒馆源码快照，包含本机对默认界面语言的修改。
- `启动酒馆.cmd`：Windows 启动入口。

酒馆源码原项目为 [SillyTavern](https://github.com/SillyTavern/SillyTavern)，
上游基准提交为 `82b64a45c34facbc98ff4b9f33c067d3ccab6a17`；许可见 `SillyTavern/LICENSE`。

以下内容只保留在本机，不上传仓库：Obsidian 的 `.obsidian` 配置与插件数据，
酒馆的本地用户数据、聊天记录、运行配置、依赖和密钥。换设备使用时，
需要重新安装依赖、启用所需的 Obsidian 插件并自行配置连接。

本仓库保存酒馆工作文件的快照，不包含酒馆内层的 `.git` 仓库及历史；
原电脑上的酒馆 Git 仓库保持独立。
